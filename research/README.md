# Контент исследования

Темы хранятся как данные, а не как разметка: один HTML собирается скриптом.

| Файл | Темы |
|---|---|
| `topics_1.py` | 01–13: механики, ИИ, графика |
| `topics_2.py` | 14–23: вода, облака, сети, процедурная генерация |
| `topics_3.py` | 24–34: физика, оптимизация, математические механики |
| `topics_4.py` | 35–44: статистика, геометрия, шейдеры |
| `topics_5.py` | 45–51: экономика, аудио, нейросети + 45 практических задач |

Каждая тема — словарь с полями:

- `n`, `id`, `cat`, `level` (1–3)
- `title`, `en`, `tags`, `summary`
- `detail` — 3 абзаца объяснения (можно с HTML: `<b>`, `<code>`, `<sub>`)
- `formula` — `(формула, пояснение)`
- `steps` — список шагов реализации
- `code` — `(язык, код)`; языки: `python`, `csharp`, `glsl`
- `complexity` — `(время, память, практика)`
- `pitfalls` — список типичных ошибок
- `games` — игры-референсы
- `demo` — необязательный ключ демо из `assets/demos-*.js`

## Пересборка

```bash
python3 tools/build.py      # → game-algorithms-research.html
```

Скрипт сам подставляет CSS, JS, собирает оглавление, карту разделов, приложение
и словарь. Внешних зависимостей нет: только стандартная библиотека Python.

## Добавление темы

1. Добавьте словарь в подходящий `topics_*.py`.
2. Для интерактивной модели — функцию в `assets/demos-a.js` / `demos-b.js`
   (`DEMOS.<имя> = function (el) { ... }`) и укажите `demo="<имя>"`.
3. Запустите сборку и откройте HTML.
