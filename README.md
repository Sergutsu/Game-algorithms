***
1. **Подходы**: Рекурсия, итеративные методы, ML, event-driven
2. **Алгоритмы**: A*, Wave Function Collapse, Raft (для сетевых), Verlet
3. **Парадигмы**: ООП, ECS (Entity Component System), функциональное, DOD
4. **Структуры данных**: Квадродеревья, графы, кольцевые буферы
5. **Оптимизации**: Spatial partitioning, memoization, job systems
6. **Архитектурные паттерны**: Команд, наблюдатель, состояние
